# ADRs (Architecture Decision Records)

Un ADR (Registro de Decisión Arquitectónica) documenta una decisión importante sobre la arquitectura del sistema, incluyendo su contexto, la decisión tomada y las consecuencias.

**Formato:** Título | Estado | Contexto | Decisión | Consecuencias
